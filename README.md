# 📊 HR Analytics Dashboard | Excel

An interactive Human Resources (HR) Analytics Dashboard built using Microsoft Excel to analyze employee data, monitor workforce metrics, and generate actionable business insights.

## 📌 Project Overview

This project focuses on analyzing HR data through an interactive Excel dashboard. It provides a visual overview of employee demographics, workforce distribution, and key human resources metrics.

The dashboard is designed to support data-driven decision-making by transforming raw HR data into meaningful insights and interactive visualizations.

## 🎯 Objectives

* Analyze employee data and workforce distribution.
* Track key HR performance indicators.
* Identify patterns and trends in employee data.
* Create interactive and user-friendly visualizations.
* Improve decision-making through data analysis.

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* PivotTables
* PivotCharts
* Slicers
* Data Cleaning & Preparation
* Data Analysis
* Dashboard Design

## 📊 Dashboard Features

The dashboard includes HR-related analysis and visualizations, such as:

* Employee overview.
* Workforce distribution.
* Department analysis.
* Employee demographics.
* Key HR performance indicators.

> Note: The exact KPIs and visualizations should be updated based on the implemented dashboard.

## 🔍 Data Analysis Process

1. **Data Collection:** Importing the HR dataset into Excel.
2. **Data Cleaning:** Reviewing data quality and preparing the dataset for analysis.
3. **Data Transformation:** Organizing data for PivotTables and dashboard reporting.
4. **Exploratory Analysis:** Examining employee-related patterns and distributions.
5. **Dashboard Development:** Creating charts, KPIs, and interactive filters.
6. **Insights Generation:** Summarizing relevant findings from the analysis.
